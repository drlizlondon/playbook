# Welcome to the Reading Room

This is a **sample document** so you can see how the Reading Room renders Markdown before you point it at your own files.

## What this is

The Reading Room turns a pile of Markdown files into one published, private web page — a reading queue you can work through and triage, on any device.

- Every doc that is still **Keep** shows its full text inline, right here.
- Each card has a **Keep / Done / Delete** control.
- Your choices save to the page's own database and sync across every device you open it on.

## How to use it

1. Expand a card to read the doc.
2. Mark it **Done** when you've read it — it collapses into the "filed" folder at the bottom.
3. Mark it **Delete** if it's noise — that's just a flag for you; nothing on disk is touched.

> The original files never move or change. This page only reads them.

Try the **Sort / organise by** dropdown at the top to switch between grouping by category and a flat, newest-first list.

That's it. Point the manifest at your real docs and rebuild.
